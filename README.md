# PLUTTO-WEB

plutto.space: the website of the Plutto astrology app (home, about, pricing,
guides, reference pages, sky calendar, panchang, free calculators, magazine)
and the app itself for browsers at `/app`.

    npm install
    npm run dev      # http://localhost:3000
    npm run build

Deployed by Vercel on every push; no configuration. What lives where, the URL
contracts and the data pipelines: [archi.md](archi.md). Web sign-in setup:
[docs/auth.md](docs/auth.md).
